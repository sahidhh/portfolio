Research

Evaluations I ran before building or adopting something.

Evaluation

Should an open-source job-search agent replace my job scraper?

Cloned a 76k-star Claude Code job-search pipeline, ran it on a fake CV, and compared it with my scraper. A scan of 94 sources found 2,758 new jobs in 73 s at zero tokens, but only ~30 were India/remote backend roles. One deep evaluation took 130 s and about $0.64 list-equivalent. Verdict: keep the scraper, adopt parts. Add on-demand deep evaluation for the top few matches, a liveness check, more ATS providers and repost detection. Estimated 10 to 14 h, against 25 to 35 h for a full replacement that would lose unattended Telegram delivery.

  • Node
  • claude -p
  • Cost model
Evaluation

Is durable execution worth adding to my agent fleet?

Reviewed a crash-recovery library for AI agents against my fleet of unattended coding-agent jobs. Every job is a single-shot run whose output a script checks, so re-running from scratch is cheaper than checkpointing, and the library's API was still changing between releases. Verdict: keep the plain runner; fix the real failures instead (retries, missed timers after a reboot). Written down with the conditions that would change the answer: multi-hour jobs or a stable 2.0.

  • TypeScript
  • systemd
  • Reliability
